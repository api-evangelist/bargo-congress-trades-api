# Bargo Congress Trades API

A free JSON REST API and hosted MCP server that normalizes U.S. House and Senate STOCK Act securities transaction disclosures, with per-trade performance data. Covers trades, members, and statistics with anonymous read access and an optional free key for higher limits.

## APIs

- **Congress Trades API** — REST API for normalized U.S. House and Senate STOCK Act stock trade disclosures, with a hosted MCP server exposing congress tools for agents. Endpoints cover trades, members, and statistics. (`https://www.bargo.ai/free-apis/congress/v1`)

> OpenAPI 3.0.3 contract and REST base URL confirmed live on bargo.ai and harvested to `openapi/` — 6 GET operations, 11 component schemas, 3 declared securitySchemes. Hosted MCP server at https://www.bargo.ai/free-apis/congress/mcp exposes three tools (get_congress_trades, get_congress_member, get_congress_stats); `tools/list` answers anonymously and its real inputSchemas are captured verbatim. Auth is optional: anonymous read is supported; a free `fak_` key (X-Api-Key header, Bearer token, or token query param) raises limits and unlocks MCP tool calls. No AsyncAPI/GraphQL/public Postman contract, no A2A agent card, no status page, no changelog, and no security.txt. Also offers an embeddable JS widget at https://www.bargo.ai/free-apis/congress/embed.js. Terms at https://www.bargo.ai/free-apis/terms; keys from https://www.bargo.ai/free-apis/dash.
